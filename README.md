
# Personal Finance Manager

Десктопное приложение для управления личными финансами.

**Тип проекта:** дипломный проект  
**Год разработки:** 2025  
**Формат работы:** индивидуальный проект  
**Моя роль:** аналитик, проектировщик и разработчик

## О проекте

Personal Finance Manager — приложение для учёта доходов и расходов, планирования бюджета, анализа финансовых операций и автоматизации регулярных платежей.

Проект выполнен в рамках дипломной работы в Колледже профессионального образования ПГНИУ по специальности 09.02.07 «Информационные системы и программирование».

## Проблема

При анализе предметной области были выделены следующие проблемы:

- Отсутствие системного подхода к учёту личных финансов.
- Сложность планирования бюджета.
- Неудобство ручного ведения финансовой отчётности.
- Ограниченность бесплатного функционала существующих приложений.
- Избыточная сложность отдельных программных решений.

## Цель проекта

Разработать приложение, позволяющее пользователю самостоятельно контролировать финансовые операции, планировать бюджет и анализировать структуру доходов и расходов.

## Целевая аудитория

- Пользователи, заинтересованные в контроле личного бюджета.
- Люди, ведущие учёт доходов и расходов.
- Пользователи, которым необходимы инструменты финансового планирования и визуализации данных.

## Анализ конкурентов

На этапе проектирования был проведён сравнительный анализ трёх существующих решений:

- CoinKeeper.
- Zen-Money.
- Домашняя бухгалтерия.

Приложения сравнивались по 7 критериям:

1. Регистрация и авторизация.
2. Визуализация данных.
3. Экспорт данных в Excel.
4. Поддержка регулярных платежей.
5. Наличие системы напоминаний.
6. Модель оплаты.
7. Стоимость использования.

На основании анализа были определены требования к функциональности собственного приложения.

## Тестирование

Проведено ручное функциональное тестирование основных пользовательских сценариев.

В процессе тестирования выявлены и исправлены 6 ошибок, связанных с авторизацией, валидацией данных, регистрацией пользователей и финансовыми операциями.

В дипломной документации представлены 8 примеров тест-кейсов с ожидаемыми и фактическими результатами.

После исправления выявленных ошибок проведено повторное тестирование.

## Пользовательское тестирование

Для оценки удобства приложения были привлечены сотрудники студии веб-дизайна «Гротеск» (г. Пермь), где проходила преддипломная практика.

После использования приложения участники заполнили анкеты и оставили комментарии.
